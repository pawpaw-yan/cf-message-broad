Webhook 密钥

调用方发送留言时携带密钥（?secret=密钥 或请求头 X-Webhook-Secret），留言署名自动使用该密钥的备注名（未填备注名则显示密钥值）。删除某把密钥即可立即吊销对应调用方；未配置任何密钥时任何人都能发送，署名为"匿名"。

如何通过 Webhook 发送留言？

向本站的 /api/messages 发送 POST 请求即可，支持 JSON、表单和纯文本：

字段兼容 message / text / content / body，署名兼容 name / author / username。
