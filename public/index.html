如何通过 Webhook 发送留言？

向本站的 /api/messages 发送 POST 请求即可，支持 JSON、表单和纯文本：

curl -X POST https://你的域名.pages.dev/api/messages \
  -H "Content-Type: application/json" \
  -d '{"name": "小明", "message": "你好，世界！"}'

字段兼容 message / text / content / body，署名兼容 name / author / username。

若服务端配置了 WEBHOOK_SECRET，请加上 ?secret=你的密钥 或请求头 X-Webhook-Secret。
